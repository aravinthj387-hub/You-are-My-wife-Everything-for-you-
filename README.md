# You Are My Wife ❤️ — Amuthamozhi

A small romantic website with the uploaded song included.

## Publish it with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `amuthamozhi-love`).
2. Extract this ZIP on your phone/computer.
3. Upload `index.html` and the `assets` folder (with `amuthamozhi.mp3`) to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait a little for deployment. GitHub will show your website URL in the Pages section.

Keep the MP3 in `assets/amuthamozhi.mp3` so the player works. Anyone with the public page link may be able to listen to the song.
